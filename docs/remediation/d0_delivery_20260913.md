## 2. 核对修正：冻结候选的真实状态

指导第 11.1 节记载"这份审校对第四卷引用失实，但后几卷重复揭露、重复晋升确有依据"。
本轮核对确认并**修正了一处推断**：

- 冻结审校的引用确实失实。它说第四卷 `volume_climax`/`ending_state` 出现"正式揭露""获取完整线索"；
  第四卷没有这两句，该句属于第五卷。
- 但**冻结候选本身没有机械缺陷**。用真实作者锁（经生产编译路径）复核：
  `volume_stage_grid_defects` 与 `missing_volume_structure_keys` 对全部 8 卷均为空，
  卷区间 1—800 连续，长程真相的两个锁边界（350 / 401）都被阶段窗口满足。
- N2 记录里提到的"21 条窗口违规"是**没有传目录**时的产物：既无作者约束也无义务目录，
  每个 `serves` 都被判为"未知 handle"。传目录后归零。这是缺目录的假象，不是候选缺陷。
- 因此旧审校被拒的真正原因是**引用失实 + 无结构化意见**，而不是候选有机械问题。
