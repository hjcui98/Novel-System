# ADR 0012: Close production content and skill contracts

Date: 2026-09-12. Status: accepted and implemented under the user's authorised repair.

## Context

The follow-up production audit found conflicting skill protocols, ineffective selection,
stale plans, incomplete ordinary curation and unsafe evidence classification. Frozen task
restoration and repair state also need to survive repeated runtime slices. Existing Canon,
artifact storage, model ledger and acceptance boundaries remain the owners of durable truth.

## Decision

Use registered, hashed method cards and selected full text with explicit mode requirements.
The host owns output schemas and permissions; methods describe operations and checkpoints.
Independent editorial evidence determines completed writing checkpoints.

Treat accepted planning scopes as replaceable active projections, retaining history through
commits. Distinguish entry conditions, invariants and exit outcomes. Bind observed fulfillment
to planned identities with prose evidence, keeping intent separate from World facts.

Process ordinary chapter changes in bounded source batches with explicit continuation and
coverage closure before atomic settlement. Use a bounded relevant World view for model input;
validation still sees the complete World. Never evict canonical artifacts to bound a cache.

Restore frozen task inputs before invoking models. Reuse completed ledger results only when
the request identity and hash match. Persist repair steps, review history and model records
before yielding, and revalidate lookahead against committed dependencies and parent scope.

## Tradeoffs and verification

Batching and independent skill assessments add calls and schema fields, but remove silent
information loss and self-certification. Bounded working sets may omit context; explicit gaps
and full-world deterministic validation remain necessary. Legacy empty-field root identities
must remain readable. Offline regressions cover actual failure paths; literary quality and
real retrieval effectiveness require real outputs and are not established by fake models.

Lookahead currently compares complete Text/World/Plan/Profile roots as a conservative dependency
set; changed roots require replanning. Ordinary curation retains a four-operation response bound,
not a chapter bound, with explicit continuation exhaustion instead of silently incomplete commits.
