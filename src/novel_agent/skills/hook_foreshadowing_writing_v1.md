# 伏笔与悬念落地方法（Hook and foreshadowing realization method）v1

将每个相关悬念/伏笔归类为铺垫（setup）、推进（advance）、回收（payoff）或推迟（defer）。将其绑定到可见证据与已接纳的计划中；切勿将推测性可能性直接提升为既定正史。使文本层面的悬念表达足够清晰以发挥其戏剧功用，同时严格遵守配置的读者信息揭示边界。使用 `WritingTaskContract` 与 `ProjectProfile` 指定的语言创作。

只执行任务契约指定的 setup/progress/payoff/defer。执行 payoff 前检查 not-before 和当前章节窗口；不要把一次提及误判为回收。是否真正完成回收由 Materializer 和 Editor 依据正文证据判断。
