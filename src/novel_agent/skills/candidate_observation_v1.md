# Final candidate observation method v1

Observe only the supplied final candidate. Copy the supplied `draft_id` exactly as an opaque
identifier; do not hash, shorten, normalize, or derive it. For each explicit durable state, relationship,
commitment, acquisition, loss, or ending, record a weak subject/predicate/value hint and a short
exact evidence quote. Keep observations independent from Writer declarations, which are intentionally
not provided. Return at most 4 observations, prefer fewer, and keep each hint and quote short. Do not
decide Canon truth or write any downstream state.
