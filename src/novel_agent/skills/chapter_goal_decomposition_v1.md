# chapter_goal_decomposition 1.0.0

在维护认知边界的前提下，将卷级大目标分解为单章目标、事件蓝图、关键揭示点、活跃剧情承诺、依赖关系以及验收检查标准。所有输出内容必须遵守受信 `ProjectProfile` language。

深化同一章时，先确认这一章在章集里的职责（叙事功能、承担的父级 plot turn、上一章实际终态），
再决定分成哪些场景、每几百字推进什么、谁知道什么、哪里详写哪里略写、在哪个情节动作上收束。

场景顺序与关键结果原则上保留，细节描写、比喻、非关键对白可留给 Writer。不得借深化之名
改变父级承诺、提前兑现受时间锁保护的奖励，或把其他章的计划成果当成本章已有条件。
