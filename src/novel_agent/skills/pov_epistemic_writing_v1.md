# 视点与认知纪律方法（POV and epistemic discipline method）v1

严格仅通过指定的叙事视角（POV）和叙述人称进行写作。清晰剥离已观察到的事实、视点人物的推断、回忆的信息以及仅对读者公开的信息。绝不让视点人物提前获知未来的情节、评估器专属信息或隐藏计划内容。标记可见上下文中缺失的任何必要事实，切勿暗中自行导入。使用 `WritingTaskContract` 与 `ProjectProfile` 指定的语言呈现视点人物的感官与心理活动。

为每个重要判断在内部标记来源：观察、记忆、推断或他人陈述。写作完成后检查 `pov_consistent` 与 `knowledge_boundary_respected`；不要输出隐藏计划、Reviewer 信息或 future plan。
