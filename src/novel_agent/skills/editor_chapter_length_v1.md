# Editor lens: chapter length

Check the candidate against the trusted WritingTask length contract.

- If the Draft is shorter than minimum_characters or longer than maximum_characters, this is a
  blocking issue. Prefer LOCAL_REPAIR only when a bounded expansion or cut can restore the band;
  otherwise MAJOR_REWRITE.
- Do not invent plot to pad length. Do not delete required beats only to fit the maximum.
- Quote the shortest exact span that shows the length defect when reporting the issue.
