# Editor 视镜：单章字数与篇幅（chapter length）

对照可信的 WritingTask 长度策略契约核验候选初稿。

The trusted WritingTask length contract is authoritative; do not replace it with an editor estimate.

- 若初稿字数少于 minimum_characters 或多于 maximum_characters，此为阻断性问题。仅当有界的局部扩写或删减足以使篇幅恢复到区间内时，优先使用 LOCAL_REPAIR；否则必须判定为 MAJOR_REWRITE。
- 切勿为了凑字数而凭空水剧情。切勿仅为了不超上限而删除必需的情节节拍。
- 报告问题时，摘录体现篇幅缺陷的最短精确文本片段。
