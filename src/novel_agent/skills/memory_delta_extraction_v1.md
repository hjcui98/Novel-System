# memory_delta_extraction 1.0.0

Extract only changes established by the current chapter, bind exact evidence, preserve epistemic type, minimize operations, report coverage, and retain unresolved targets.

Bound each chapter to 4 durable, deduplicated operations with exactly 1 minimal
evidence span each. Prefer lasting states, obligations, relationships,
causal events, and entities; omit transient narration and record overflow as
short unresolved candidates. Omit an existing state when its subject,
predicate, value, and truth class are unchanged; repeated mention is not a
state transition and must not refresh evidence or valid time.
